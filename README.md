# EzEizoV2

גרסת Windows מקומית לטכנאי ולמנהל. פיתוח נפרד מ־[EzEizo](https://github.com/cartonush/EzEizo).

הגיבוי המדויק של גרסת האתר 1.6.3: `EzEizo` branch `backup-v1.6.3-2026-11-20`, commit `d3c7efa8eac925aa206a4fda40f086fa27001a99`.

## גרסת Windows ראשונית

קוד המקור לשני יישומי WinForms x64 נמצא ב־`src/`. תהליך הבנייה ב־`.github/workflows/windows-build.yml` יוצר חבילה להורדה עם `EzEizo-Metis.exe`, `EzEizo-Mechanic.exe` ו־`data/EzEizo.accdb` ריק. הוראות והיקף ההדגמה מפורטים ב־`INSTALL-WINDOWS.md`.

זוהי גרסת אב טיפוס מקומית עם זרימת תקלה בסיסית, והיא אינה מכילה עדיין את כל מסכי האתר. אין להעלות קובצי `.accdb` עם נתונים אישיים או חתימות למאגר ציבורי.
